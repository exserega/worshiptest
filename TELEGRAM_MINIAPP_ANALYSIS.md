# 📱 Анализ интеграции Agape Worship с Telegram Mini App

## 📊 АНАЛИЗ ТЕКУЩЕГО ПРОЕКТА

### Что такое Agape Worship?
**Agape Worship** — это полнофункциональное веб-приложение (PWA) для управления песнями поклонения в церковных филиалах.

### Основные функции проекта:

#### 1. **База данных песен** 🎵
- 📚 Хранение текстов песен с аккордами в Firebase Firestore
- 🔍 Мощный поиск с фаззи-логикой (нечеткий поиск)
- 📂 Категоризация: "Быстрые", "Поклонение" (вертикаль/горизонталь)
- 🎬 YouTube интеграция для видео/аудио
- 📝 Редактирование песен (персональное и глобальное по филиалу)

#### 2. **Транспонирование аккордов** 🎸
- Автоматическое транспонирование в любую тональность
- Поддержка диезов (#) и бемолей (♭)
- Интеллектуальная система выбора нотации
- Поддержка сложных аккордов (maj7, m9, sus4, dim, aug и др.)
- Обработка басовых нот (например, C/E)

#### 3. **Сет-листы (плейлисты)** 📋
- Создание и управление списками песен для служений
- Drag & Drop для изменения порядка песен
- Привязка к филиалам церквей
- Сохранение тональности для каждой песни в сет-листе
- Режим презентации (полноэкранный просмотр)
- Архив сет-листов с системой групп и тегов

#### 4. **События/Служения** 📅
- Календарь событий с несколькими режимами отображения
- Привязка сет-листов к событиям
- Управление участниками по инструментам
- Публичные ссылки для шаринга
- Интеграция с WhatsApp/Telegram для отправки деталей
- Уведомления участникам о новых событиях

#### 5. **Система ролей и филиалов** 👥
- **Роли**: admin, user, guest, pending
- **Филиалы**: множественные церковные филиалы
- **Права доступа**: детальный контроль по филиалам
- **Заявки**: система одобрения новых пользователей
- Гостевой доступ без регистрации

#### 6. **Репертуар вокалистов** 🎤
- Персональные списки песен для каждого вокалиста
- Сохранение предпочтительной тональности
- Фильтрация по категориям и тональностям

#### 7. **Дополнительные функции**
- 🥁 Встроенный метроном с визуальным индикатором
- 📱 PWA с офлайн-поддержкой
- 🌙 Темная тема (единственная)
- 📋 Копирование текстов песен
- 🔊 Интеграция с YouTube плеером

## 🤔 TELEGRAM MINI APP: ЧТО ЭТО?

### Что такое Telegram Mini Apps?
**Telegram Mini Apps** (ранее Web Apps) — это веб-приложения, которые запускаются внутри Telegram:
- Открываются в WebView внутри мессенджера
- Имеют доступ к Telegram API через JavaScript
- Могут быть запущены из бота, канала, группы или меню
- Не требуют установки из магазинов приложений

### Технические особенности:
- **Размер**: До 10 MB (рекомендуется < 2 MB)
- **Технологии**: HTML, CSS, JavaScript
- **API**: Telegram WebApp API
- **Авторизация**: Через Telegram (не нужны сторонние OAuth)
- **Платежи**: Telegram Payments встроены
- **Хранение**: localStorage, IndexedDB

### Ограничения:
- ❌ Нет доступа к файловой системе устройства
- ❌ Ограниченный доступ к нативным API
- ❌ WebView может иметь ограничения безопасности
- ❌ Размер приложения ограничен
- ⚠️ Firebase может иметь проблемы в некоторых WebView

### 1. Создание Telegram бота (готовый код)

```javascript
// bot.js - Простой стартовый бот
const TelegramBot = require('node-telegram-bot-api');

const token = 'YOUR_BOT_TOKEN';
const bot = new TelegramBot(token, {polling: true});

// Команда /start
bot.onText(/\/start/, (msg) => {
  const chatId = msg.chat.id;
  
  bot.sendMessage(chatId, 'Добро пожаловать в Agape Worship! 🎵', {
    reply_markup: {
      inline_keyboard: [[
        {
          text: 'Открыть приложение',
          web_app: { url: 'https://agapeworship.asia' }
        }
      ]]
    }
  });
});

// Команда /song - поиск песни
bot.onText(/\/song (.+)/, async (msg, match) => {
  const chatId = msg.chat.id;
  const query = match[1];
  
  // Поиск в Firebase
  const songs = await searchSongs(query);
  
  if (songs.length > 0) {
    const song = songs[0];
    bot.sendMessage(chatId, 
      `🎵 ${song.name}\n\n` +
      `Тональность: ${song.defaultKey}\n` +
      `Категория: ${song.sheet}`,
      {
        reply_markup: {
          inline_keyboard: [[
            {
              text: 'Открыть песню',
              web_app: { url: `https://agapeworship.asia?song=${song.id}` }
            }
          ]]
        }
      }
    );
  } else {
    bot.sendMessage(chatId, 'Песня не найдена 😔');
  }
});

// Функция поиска (интеграция с Firebase)
async function searchSongs(query) {
  const admin = require('firebase-admin');
  const db = admin.firestore();
  
  const snapshot = await db.collection('songs')
    .where('name', '>=', query)
    .where('name', '<=', query + '\uf8ff')
    .limit(5)
    .get();
    
  return snapshot.docs.map(doc => ({
    id: doc.id,
    ...doc.data()
  }));
}
```

### 4. Firebase Cloud Function для уведомлений

```javascript
// functions/index.js
const functions = require('firebase-functions');
const admin = require('firebase-admin');
const TelegramBot = require('node-telegram-bot-api');

admin.initializeApp();
const bot = new TelegramBot(process.env.TELEGRAM_BOT_TOKEN);

// Отправка уведомления при создании события
exports.sendEventNotification = functions.firestore
  .document('events/{eventId}')
  .onCreate(async (snap, context) => {
    const event = snap.data();
    const participants = event.participants || [];
    
    for (const participant of participants) {
      // Получить Telegram ID пользователя
      const userDoc = await admin.firestore()
        .collection('users')
        .doc(participant.userId)
        .get();
        
      const telegramId = userDoc.data()?.telegramId;
      
      if (telegramId) {
        await bot.sendMessage(telegramId,
          `🔔 Новое событие!\n\n` +
          `📅 ${event.name}\n` +
          `📆 ${event.date.toDate().toLocaleDateString()}\n` +
          `🎵 Песен: ${event.songCount}`,
          {
            reply_markup: {
              inline_keyboard: [[
                {
                  text: 'Подробнее',
                  web_app: { 
                    url: `https://agapeworship.asia/public/event/?id=${context.params.eventId}` 
                  }
                }
              ]]
            }
          }
        );
      }
    }
  });
```
